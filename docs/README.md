# Nuxpad 2

**Simple. Fast. Focused.**

Nuxpad 2 is a lightweight plain-text editor for Linux and Windows, built with Python and PyQt6 from one shared source.

Highlights include safe encoding/BOM/line-ending handling, atomic ordinary-file saves, SHA-256 external-change detection, multiple windows, drag and drop, bounded search highlighting, printing, Linux AppImage themes, Windows Character Map, and Linux host character-map launching.

Repository: https://github.com/brunonlinespace/nuxpad.py
